# Who Wrote It? Identifying LLMs from Their Responses

CMPSC 448 midterm project. Given a response written by a large language model, predict which LLM family
wrote it: **GPT, Claude, Gemini, Llama, Qwen or DeepSeek** (6 classes, chance = 16.7%).
Both required models are implemented in PyTorch: a **TextCNN** and a **bidirectional LSTM**.

The full write-up is in [`report/Project_Report.pdf`](report/Project_Report.pdf).

## Data

* Source: public model outputs from **AlpacaEval** ([tatsu-lab/alpaca_eval](https://github.com/tatsu-lab/alpaca_eval),
  Apache-2.0), commit `cd543a149df89434d8a54582c0151c0b945c3d20`, files `results/<model>/model_outputs.json`.
* Every model answered the **same 805 instructions**, so the data are parallel and perfectly balanced.
  One prompt with an empty Gemini answer is dropped for all models -> **804 prompts x 6 families = 4,824 triples**
  `(LLM_name, LLM_input, LLM_output)`.
* Models: `gpt-4o-2024-05-13`, `claude-3-opus-20240229`, `gemini-pro`, `Meta-Llama-3-70B-Instruct`,
  `Qwen1.5-72B-Chat`, `deepseek-llm-67b-chat`. Held-out siblings for the cross-version test (RQ3):
  `gpt-4-turbo-2024-04-09`, `claude-3-5-sonnet-20240620`, `Meta-Llama-3.1-70B-Instruct-Turbo`, `Qwen2-72B-Instruct`.
* Split **by prompt** 70/15/15 (562/120/122 prompts), so no test prompt is ever seen in training.
* No private or personal data: prompts come from public benchmarks (Self-Instruct, OASST, Koala, Helpful-Base, Vicuna).

## Repository layout

```
data/raw/                 raw AlpacaEval output files (10 models)
data/processed/           dataset.csv, siblings.csv, splits.json   (built by prepare_data.py)
src/prepare_data.py       builds the dataset, task-domain labels and the prompt-level split
src/common.py             tokenizer, vocabulary, TextCNN, BiLSTM, training loop with early stopping
src/ablations.py          text transformations for RQ4 (strip markdown, style skeleton, ...)
src/run_nn.py             every CNN / LSTM experiment (RQ1-RQ4); one JSON per run in results/nn/
src/run_sklearn.py        TF-IDF + logistic regression baseline, stylometric features, n-grams (RQ2-RQ4)
src/cnn_filters.py        which n-grams the trained CNN's filters respond to (RQ4)
src/make_figures.py       aggregates results -> results/summary.json and figures/*.png
report/build_report.py    builds report/Project_Report.pdf from results/summary.json
report/team.json          team leader / member names and repo URL shown on the report title
```

## How to reproduce

```bash
pip install -r requirements.txt
python src/prepare_data.py                    # (optional: bash src/download_data.sh to re-download raw files)
python src/run_sklearn.py                     # baselines + stylometry, ~3 min
python src/run_nn.py --queue cnn              # all CNN runs   (CPU: about 1-1.5 h)
python src/run_nn.py --queue lstm             # all LSTM runs  (CPU: about 1.5-2 h; can run in parallel with the CNN queue)
python src/cnn_filters.py
python src/make_figures.py
python report/build_report.py
```

Each run writes `results/nn/<run>.json` and is skipped if that file exists, so queues can be interrupted and resumed.
Set `THREADS=1` when running the two queues side by side on a 2-core machine.

## Research questions covered

| RQ | Question | Where |
|----|----------|-------|
| RQ1 | Identify the LLM from its output (CNN + LSTM, 3 seeds) | report section 4 |
| RQ2 | Input only vs output only vs input + output, plus a confounded-collection experiment | section 5 |
| RQ3 (extra) | Cross-task (writing / code-math), leave-one-prompt-source-out, unseen model versions | section 6 |
| RQ4 (extra) | Stylometric features, discriminative n-grams, CNN filters, openers, 6 text ablations | section 7 |
